🔌One-time setup Connect this page to Anki desktop
  1. Open Anki desktop → Tools → Add-ons → Get Add-ons, paste code 2055492159 (AnkiConnect), restart Anki.
  2. Tools → Add-ons → AnkiConnect → Config, and add this site to webCorsOriginList:
"webCorsOriginList": [
    "http://localhost",
    "https://reboufv.github.io"
]
  1. Restart Anki and keep it open. If the browser asks whether this site can access devices on your local network, click Allow.
  2. The status pill at the top turns green.

Good to know

  • Works in Chrome, Edge and Firefox on the computer where Anki runs. Safari blocks it.
  • On your phone, use Save to queue. The queue lives in that browser, so either sync from the same device or use Export CSV and import it in Anki (File → Import, "Allow HTML" on).
  • Opening this file directly from disk (file://) needs "null" in the list too.
