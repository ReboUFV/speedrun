🧮How the math works 
mastery m = (correct + 1) / (questions + 2)
            2/2 → 0.75 · 1/2 → 0.50 · 0/2 → 0.25
need      = topic weight (1–3, exam relevance) × (1 − m)
fit       = A1–B1 unit: 1 if m < 0.75, else 0.35
            B2–C1 unit: 1.2 if m ≥ 0.5, else 0.25
done      = 0.5 if you already did the unit
cost      = 1 slot (½ for a repeat of a done unit)
score     = need × fit × done ÷ cost

Your pace: 2 core + 1 optional extra unit per day
(mock days 1 + 0) until Gate 3 on Nov 1.
Highest scores fill the core slots, the next ones
the extra slots. Score < 0.3 or no slot left
→ not needed.

The fit rule stops you jumping to B2–C1 units on a topic where the A-level basics are still broken. That's the most common way to waste hours.
