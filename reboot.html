Why this exists
Grammar is a puzzle for you; vocab isn't. So turn vocab into rules. Your C2 English decodes the Germanic core, your Spanish decodes the Latin layer (Information, Universität, Situation, Diskussion). Anki only what these rules can't decode.
Rule 1 · Gender by suffix (free articles)
die: -ung, -heit, -keit, -schaft, -ion, -tät, -ik, -ie, -enz/-anz (Freiheit, Meinung, Lösung)
das: -chen, -lein, -ment, -um, -nis (mostly), nominalized verbs (das Lernen)
der: -ling, -ismus, -or, -er for people/tools (der Lehrer, der Computer)
Rule 2 · Word-building suffixes
-weise ≈ -mente: glücklicherweise, beispielsweise
-bar ≈ -able: machbar, trinkbar · -los ≈ -less / sin: arbeitslos, sinnlos
-lich / -ig ≈ -ly / -y: freundlich, wichtig
Rule 3 · Consonant shift (EN → DE)
t → z/s/ss: two → zwei, water → Wasser, ten → zehn
p → f/pf: apple → Apfel, sleep → schlafen, open → offen
d → t: day → Tag, door → Tür, dance → tanzen
th → d: think → denken, thing → Ding, three → drei
Rule 4 · Prefix = direction (≈ phrasal verbs)
auf ≈ up/open (aufgeben = give up, aufmachen = open) · zu = closed (zumachen)
an / aus = on / off-out (anmachen; ausmachen = switch off / agree on; ausgehen = go out)
ab ≈ off/away (abschneiden, absagen = cancel) · ein ≈ in/into (einkaufen, einschlafen)
um = change/around (umziehen = move house) · vor = fore/pre (vorbereiten, vorstellen)
ver- often = wrong/away/changed state (vergessen, verlieren, sich verlaufen = get lost) · er- = reach a result (erreichen, erfahren)
Rule 5 · Compounds are descriptions
Last part = meaning + gender: Hand + Schuh = der Handschuh, kühlen + Schrank = der Kühlschrank. Split long words before you look them up.
Lesen (65 min)
Read the questions first, then scan for them. Never translate whole texts in the exam. Paraphrase hunt: the correct answer almost never reuses the question's words (Arbeit → Beruf, schnell → rasch). Identical words in text and option are often the trap. If a statement sounds logical but isn't actually in the text → it's wrong. Hard time-box per Teil; if stuck >90 s, guess and move. Never leave a blank.
Hören (~40 min)
Use the pause before each audio to underline key words in the questions. Expect distractors: speakers often mention several options. Listen for the turn after aber / jedoch / trotzdem / eigentlich; the real answer often comes right after it. Mark an answer during the first play; only confirm on replay.
Mock post-mortem (after every mock)
For every wrong answer write: why (vocab / grammar / trap / time). Anki the vocab ones. The most frequent "why" decides your next fix-it day.
